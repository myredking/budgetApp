# RPG port artwork

Generated using the built-in image generation tool. Original illustrated assets; no existing game art was used. PNG files retain generated pixels and ship transparency. Runtime source rectangles select atlas cells; no image editing was performed.

- `assets/town-scenes-v1.png`: actual 887×1774 RGB, 2 columns × 4 rows. Row major: Northern Europe, Mediterranean, Africa, Indian Ocean, Southeast Asia, East Asia, Caribbean, shipyard.
- `assets/facility-scenes-v1.png`: actual 887×1774 RGB, same regional order for seven trading houses; last cell tavern.
- `assets/sailing-ships-v1.png`: actual 1536×1024 RGBA, three columns: sloop, caravel, galleon. Bow points upward. Transparent background preserved.

The generated town panels are approximately square rather than the landscape panels requested in the prompt. The app displays the actual square cells without inventing extra art.
The first town row has its divider at x=518 of 887, rather than the midpoint. Runtime source rectangles account for this observed boundary.

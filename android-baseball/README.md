# 덱볼 야구 / DeckBall 0.4.0 — 2026 × LEGENDS

안드로이드 8.0 이상 / OpenGL ES 2.0 지원 기기용 오프라인 3D 야구 시제품입니다. 첨부 참고 화면의 가로 배치, 타석 시점, 양쪽 선수 카드, 상단 점수판 구성을 참고해 직접 그린 화면을 사용합니다.

## 설치 / 사용

1. `DeckBall.apk`를 휴대폰으로 옮겨 설치합니다. 기존 개발판과 같은 서명입니다.
2. **선수 덱 / 타순 편집**에서 타자 9명과 투수 1명을 고릅니다. ↑로 타순을 변경합니다.
3. **능력치 직접 수정**에서 실제 선수와 커스텀 선수의 컨택·파워·제구를 1~99로 수정합니다. 원본 시즌 기록은 보존됩니다.
4. **난이도**에서 쉬움·보통·어려움을 고릅니다. 투구 이동 시간은 각각 2300/1700/1200ms, 타이밍 허용 폭은 ±0.12/0.07/0.045입니다. 판정 허용도와 자동 진행 확률에도 반영됩니다.
5. **상대 대표 선수 선택**에서 상대 타자·투수를 지정할 수 있습니다. 상대 선수 능력치도 판정에 반영됩니다. 대표 타자 1명이 반복 출전하는 단순화한 상대 구성입니다.
6. 타격은 투구 요청 후 노란 구간에서 스윙, 투구는 구종·코스 선택 후 투구 준비 → 릴리스를 누릅니다. 감독 모드는 자동 진행입니다.
7. 현재 덱·저장 덱 3개·커스텀 선수·수정 능력치·난이도·상대 선수 선택은 재실행 후 복원됩니다.

0.1 버전의 가상 선수 덱은 2026 선수 덱과 저장 키를 분리했습니다. 첫 실행 시 다시 편성하도록 안내하며, 기존 커스텀 선수는 보존합니다. 진행 중 경기는 저장하지 않습니다.

## 2026 선수 기록

2026-11-04 KBO 공식 기록실에서 **2026 / 정규시즌**을 선택해 조회한 기록의 오프라인 스냅샷입니다. 최신 기록을 자동 조회하지 않습니다. 시즌 소속 구단을 사용합니다.

- 현역 시즌 카드 18명: 10개 구단 대표 타자 10명, 대표 투수 8명. 전체 구단 선수 명단은 아닙니다.
- 역대 카드 15명: 이승엽·장효조·이만수·한대화·이정훈·양준혁·이종범·마해영·박종호·장성호·최동원·선동열·송진우·이상훈·정민태. 각각 기록 시즌을 표시합니다. 이 앱의 역대 카드 분류이며 공식 ‘레전드 40인’ 명단과 동일하지 않습니다.
- `data/roster-2026.json`: 실제 게임 카드와 원자료 URL.
- `data/*-source.json`: 조회한 타자·투수·역대 기록 및 이승엽 56홈런 근거.
- `KboRoster.java`: APK에 포함되는 카드 명단.

## 개발 / 검증

```powershell
python android-baseball/tools/bootstrap.py
python android-baseball/tools/build.py
python -m pytest tests/test_android_baseball.py -q
python -m radon cc android-baseball/tools tests/test_android_baseball.py -s
python -m lizard android-baseball/src android-baseball/tests android-baseball/tools/preview -T cyclomatic_complexity=10 -T length=50 -w
python android-baseball/tools/render_preview.py
```

`previews/field-2026.png`는 **실제 FieldView 코드**를 데스크톱 Java2D 호환 계층으로 그린 경기장 미리보기입니다. Android 기기 캡처가 아니며 네이티브 버튼/메뉴 영역은 포함하지 않습니다. 미리보기 호환 계층은 APK에 포함되지 않습니다.

엔진·설정 복원·난이도·상대 선택·잘못된 입력의 원자성 회귀 테스트 통과. APK v2/v3 서명 검증 통과. 함수 길이 50줄/복잡도 10 기준 통과. 저장소 전체 `pytest tests -q`: 291 통과, 별도 블록 게임 테스트 2건·기존 여행 웹 런타임 테스트 1건 실패. 야구 관련 테스트는 통과했습니다.

실제 기기 또는 에뮬레이터의 화면·터치·설치·재실행 검증은 아직 수행하지 못했습니다. 3이닝의 단순 확률 규칙을 사용하며 파울·도루·병살·불펜 교체·연장·온라인은 구현하지 않았습니다. 사진 기반 실사 얼굴, 고해상도 유니폼 텍스처와 모션 캡처는 구현하지 않았습니다. 원작 APK·로고·이미지·음원·얼굴 모델을 사용하지 않았습니다.

## 구단 운영 / 특수 능력

홈의 ‘구단 운영 / 스카우트’에서 운영 모드를 시작합니다. 초기 선수 10명과 예산 25000만원으로 시작하며, 자유 편성 모드로 돌아갈 수 있습니다. 조사비는 500만원, 소요 시간은 게임 내 2일입니다. 다음 날 버튼 또는 경기 완료로 날짜가 진행됩니다. 보고서 완료 후 표시된 영입비로 계약하면 라인업에 사용할 수 있습니다. 이미 조사/영입한 선수의 중복 결제와 예산 부족 결제는 거절합니다. 경기 완료 시 승리 2000만원, 그 외 800만원을 한 번 지급합니다. 실제 계약금/구단 재정과 무관한 게임용 경제입니다.

능력치 수정 화면의 ‘특수 능력’에서 최대 2개를 지정할 수 있습니다. 정교한 타격(컨택+6), 거포 본능(파워+8), 해결사(2·3루 주자 존재 시 컨택+10), 정밀 제구(제구+8), 레전드 아우라(컨택·파워·제구+3). 투수와 타자에 맞는 능력만 선택할 수 있으며 효과 적용 후 최대 110입니다. 실제 선수의 성격/공식 평가가 아닌 게임용 설정입니다. 자동 경기와 직접 조작에 모두 적용됩니다.

범위 밖 안타 거리·구종·코스·타이밍, 비정상 숫자, 빈 저장 값을 거절하도록 보완했습니다. 구단 운영의 영입 상태·예산·날짜·조사와 특수 능력은 저장됩니다. 기존 0.2 능력치 저장 형식도 읽습니다.

## 0.3 실제 3D 경기 화면

경기 화면은 GLSurfaceView / OpenGL ES 2.0에서 실제 입체 메시를 그립니다. 경기장·관중석·조명탑·전광판·마운드·선수·배트·공은 깊이 검사를 사용하는 3D 도형입니다. 원근 카메라 2개, 조명/법선 음영, 잔디 줄무늬와 표면 질감, 투구 자세·스윙·타구 이동을 구현했습니다. 구단을 참고한 색상을 쓰며 로고는 포함하지 않습니다.

선수 모델은 자체 제작한 기본 모델이며 실제 선수 얼굴/체형을 재현한 모델이 아닙니다. 상용 게임 수준의 실사 품질은 아닙니다. 경기 결과는 타이밍과 능력치의 확률 판정이며 배트/공 충돌을 물리 시뮬레이션하지 않습니다. 기존 2D FieldView는 이전 버전 미리보기 도구에만 남아 있고 실제 앱의 홈/경기는 BallparkView를 사용합니다.

카메라 전환 버튼으로 타석/측면 시점을 바꿉니다. 경기장 위의 네이티브 HUD는 선수의 효과 적용 후 능력치와 특수 능력을 표시합니다. 3D 스레드에는 불변 모션 스냅샷을 전달하며 앱 일시 중지/화면 전환 시 렌더링을 멈춥니다. 기기 시계 변경이 투구 타이밍에 영향을 주지 않도록 단조 증가 시간을 사용합니다. 자동 모드 전환 때 남던 투구 타이밍 표시를 초기화했습니다.

3D 미리보기 재생성(Windows, JDK 및 OpenGL 3.3 그래픽 장치 필요):

```powershell
python -m pip install -r android-baseball/tools/requirements-preview.txt
python android-baseball/tools/render_3d_preview.py
```

`previews/field-3d-2026.png`는 앱과 같은 메시·카메라·셰이더 조명 로직을 PC GPU에서 렌더링하고 실제 MatchOverlay 코드를 합성한 화면입니다. Android 기기 캡처는 아니며 Android 기기 성능/설치/터치 검증을 대체하지 않습니다. 셰이더의 데스크톱 문법 변환과 HUD 글꼴 차이가 있습니다. 실제 메뉴 버튼 영역은 미리보기에 포함하지 않습니다.

3D 메시의 좌표/법선/삼각형, 카메라, 공 이동, 애니메이션 자세 변경을 JVM 테스트로 검사하고 PC 그래픽 장치에서 렌더링을 확인했습니다. `requirements-preview.txt`의 라이브러리는 PC 미리보기에만 사용되며 APK에는 포함되지 않습니다.

모바일 최소 부동소수점 정밀도에서 질감 계산이 넘치지 않도록 해시 중간값을 제한했습니다. 애니메이션은 최대 32개의 포즈 캐시와 재사용 메시/직접 버퍼를 사용합니다. 같은 공 상태에서 타자와 투수의 골격 자세가 바뀌는지 각각 검사합니다.

타격/릴리스 후 PERFECT·GOOD·EARLY·LATE 타이밍 판정을 표시하고, 직전 플레이에서 실제 발동한 특수 능력을 별도로 표시합니다. 해결사는 득점권 주자가 없을 때 ‘대기’로 표시됩니다.

## 선수 관리 편의성

구단 운영에 관심 선수 등록/해제·관심 명단 필터·예산 내 보강 추천을 추가했습니다. 추천은 현재 편성의 약한 타자 또는 선발투수 대비 게임용 능력치 향상을 영입 비용으로 나눈 순서이며, 미조사 후보는 조사비까지 예산에 포함합니다. 공식 스카우트 평가가 아닙니다. 관심 명단은 저장되고, 이전 관심 명단 없는 구단 저장도 읽습니다.

라인업과 구단 운영 화면은 선수 목록과 스크롤 가능한 도구 메뉴를 좌우로 배치하여 작은 가로 화면에서 아래 버튼 때문에 선수 목록 높이가 사라지던 문제를 수정했습니다.

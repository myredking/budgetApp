- 기존 v2 APK 설치 후 같은 서명으로 v3 업데이트 설치 성공.
- 시작 화면, 난이도별 작전 목록, 전장, 일시정지와 설정 화면을 캡처하여 확인.

- 전투 중 홈으로 나갔다 복귀: 자동 일시정지 화면 확인.
- 효과음·진동을 끄고 강제 종료·재실행: 설정 유지 확인.
- 승리 직전 상태를 가상 기기에 주입하여 별 3개 지급과 다음 작전 해금을 확인.

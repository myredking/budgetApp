# Graphics refresh

Built-in ImageGen generated `res/drawable-nodpi/battlefield.png`; the project bundles the final image. Buildings, soldiers and UI are native Canvas artwork.

Final prompt: polished 3D clay diorama island battlefield, top-down orthographic near-vertical camera, portrait 3:4, smooth open mint-green meadow, turquoise water around a narrow rocky rim, tiny trees and stones only along the outer 8%, central 84% open for movable buildings, upper-left sunlight, matte clay textures; no buildings, units, text, grids or UI in the background image.

The image was copied from the built-in tool output into the project without modification. Roofs, walls, windows, antennas, flags, infantry formations, count badges, team colors and paper UI are drawn at runtime.

# 타워 프론트

Android 8.0 이상에서 실행되는 오프라인 타워 점령 전략 게임입니다.

- 아군 타워를 누르고 목표를 누르거나 드래그하여 병력 절반을 보냅니다.
- 아군과 적군은 병력을 자동 생산합니다. 중립 타워는 생산하지 않습니다.
- 이동 병력이 도착하면 증원 또는 전투가 일어납니다.
- 적 타워와 이동 중인 적 병력을 모두 제거하면 승리합니다.
- 다음 작전으로 갈수록 적 병력과 생산량이 증가합니다.
- 일시정지와 재도전 지원. 해금된 현재 작전 번호는 저장됩니다.
- 앱을 종료하면 진행 중인 전투는 초기화됩니다.

설치 파일: TowerFront.apk (개발용 서명). 휴대폰으로 옮겨 열고 해당 파일 제공 앱의 설치 허용을 선택하세요.

## 검증
전투 규칙은 Java 단독 테스트로 검증했습니다. APK 빌드 및 서명 검증 통과.
실제 Android 기기/에뮬레이터의 화면·터치·일시정지 동작은 검증하지 않았습니다.

## 빌드
기존 로컬 Android 도구를 사용하는 `python android-tower-front/tools/build.py`.
테스트: 로컬 JDK로 Engine.java와 tests/EngineTest.java를 컴파일하고 com.towerfront.EngineTest 실행.

추가 검증: 13개 전투 규칙 검사 통과. 빌드 도구 radon 복잡도 A(2).
저장소 전체 pytest는 기존 outputs 내 외부 패키지 수집 오류로 중단되었습니다.
범위를 tests로 제한하면 288개 통과, 기존 야구 앱 및 웹 기능 검사 2개 실패했습니다.
타워 프론트 외의 파일은 수정하지 않았습니다.

## 2단계 (2.0.0)
- 생산 타워: 병력 생산량 1.7배.
- 기동 타워: 해당 타워에서 출발한 병력의 이동 시간 40% 감소.
- 아군 타워 선택 후 하단 생산 강화 버튼: 병력 20/40을 소모해 Lv.2/Lv.3으로 강화.
- 레벨당 기본 생산량의 50% 추가. 점령 후에도 타워 종류와 레벨 유지.
- 작전별 좌우/상하 반전 배치 3종을 순환.
- 기존 13개 전투 검사 및 PhaseTwoTest 통과, APK 서명 검증 통과.
- 실제 Android 기기에서 터치 조작을 검증하지 못한 제한은 동일합니다.

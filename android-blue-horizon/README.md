# 푸른 수평선 — 세계 항해 Android 시제품 0.10

혼자 즐기는 세로 화면 항해·무역 게임. Android 8.0 이상, 인터넷·로그인·광고 없이 실행합니다.
원작의 코드·인물·대사·음원·이미지를 사용하지 않은 독립 창작입니다.

## 0.10 완성도 개선: 성장·화물 보호·빠른 항해

선박 등급은 기본 항해일수에도 영향을 줍니다. 슬루프 100%, 캐러벨 80%, 갤리온 65%를 적용한 뒤 올림하며 최소 이틀을 유지합니다. 돛 개조는 추가 반영됩니다. 일수가 짧아지므로 항해 보급비도 줄어듭니다. 기존 저장 형식 BLUE8은 유지됩니다.

판매 주문서에는 ‘이야기·의뢰·경주용 화물 남기기’가 기본 적용됩니다. 전량 판매는 목표용 화물을 제외한 수량을 뜻하며 명세서에 보관 수량을 표시합니다. 체크를 해제하면 원래처럼 모두 팔 수 있습니다. 이야기용 화물은 목적지 도착과 선행 항구 방문 등 실제 완료 조건이 갖춰지면 판매할 수 있습니다. 의뢰·경주는 납품 전까지 보관하고, 기한이 지나면 보호에서 제외합니다.

항해 연출은 1×/2×/4×로 선택할 수 있고 기기에 선택을 기억합니다. 배속은 화면 재생 시간에만 적용되며 보급비·게임 내 항해일수·사건 결과는 변하지 않습니다. 앱을 벗어나면 연출 진행이 멈추고 돌아와 이어집니다. 건너뛰기도 유지됩니다.

실제 사건·선택·저장 복원을 포함하는 자동 캠페인 점검을 추가했습니다. 아홉 번의 초반 목재 교역 후 본 줄거리를 따라가며 부족한 금화를 항구 일거리로 채우는 동일 경로에서, 작업 105→93회, 게임 내 498→420일로 줄었습니다. 최적 공략이나 실제 플레이 시간 측정은 아니며, 탐험 보상을 활용하지 않은 단순 경로의 비교입니다.

## 0.9 잊힌 항로: 지도·인연·강적

마을이나 모험 메뉴에서 **잊힌 항로**를 엽니다.

1. 같은 해역의 서로 다른 항구에서 기록을 조사합니다. 항구당 단서는 한 번, 조사비 40 G와 하루가 듭니다.
2. 조각 세 개를 모으면 보물 탐사 항구가 지도에 표시됩니다. 그곳에 직접 입항해 탐사비 80 G·하루를 쓰면 해역별 보물과 900~1800 G, 명성 3, 사기 10을 받습니다. 보물은 한 번만 받을 수 있습니다.
3. 동료 화면에서 합류한 동료와 선택형 대화를 나눕니다. 동료 다섯 명당 두 대화가 있으며, 두 번째는 보물 하나와 합류 후 이야기 한 장 진행이 필요합니다. 마음 나누기는 신뢰 +2/사기 +10, 실행 계획은 신뢰 +1/명성 +1입니다. 선택은 저장됩니다.
4. 보물을 찾은 해역의 강적에 도전합니다. 선체 40 이상, 지역에 따라 선박 등급 1/2/3이 필요합니다. 집중 포격·방어 사격·후퇴를 고르며 적의 다음 행동이 공개됩니다. 동료 신뢰 합계 4마다 강적전 포격 +1(최대 +3)을 받습니다.
5. 승리하면 해역별 훈장·1200~3000 G·명성 5를 한 번 받습니다. 후퇴는 선체 4/사기 5/하루를 사용하고, 다시 도전하면 적은 완전한 상태로 시작합니다. 패배가 저장 삭제로 이어지지는 않습니다.

강적 전투 중에는 교역·항해 등 다른 행동이 잠기며, 앱 재실행과 파일 불러오기에서 같은 전투를 이어갑니다. 저장 형식 BLUE8은 BLUE1~7을 읽습니다. 보물·대화·강적은 창작 이야기의 선택형 추가 콘텐츠입니다.

## 0.8 항구 플레이와 움직임 개선

- 마을 상단의 ‘선장의 다음 한 걸음’에서 필요한 물품 주문·목적지 항해·도착 후 판매·의뢰 납품·달성 보상으로 바로 이어집니다. 현재 항구에서 완료할 수 있는 납품은 수리 안내보다 먼저 표시합니다.
- 마을 건물이나 버튼을 누르면 작은 선장 캐릭터가 길을 따라 걸어가 입장합니다. 중복 클릭은 한 번만 처리하고, 다른 화면이나 앱으로 이동하면 걸음을 취소합니다.
- 교역소의 배경과 안내를 간결하게 정리해 상품 가격·선택·주문 버튼이 더 빨리 보입니다.
- 의뢰 게시판에 가벼운 운송·기한 우선 운송·대량 교역이 나옵니다. 현지 화물 매입과 안전항로 보급비를 고려한 보상이며, 수리·귀환·항해 사건 비용은 별도입니다. 완료 횟수에 따라 제안이 바뀌고 취소로는 다시 뽑지 않습니다.
- 활동 경험 80마다 선장 등급이 올라가며, 등급 5/10/15에 포격 숙련 +1씩(최대 +3)을 받습니다. 사기 효과와 합산됩니다. 기존 저장의 활동 기록에도 적용됩니다.
- 배가 실제 항로 방향으로 선회하고 물살도 선미를 따라갑니다. 미니 지도에 해안선과 현재 위치가 보이며 회전 크기를 제한해 화면 밖으로 잘리지 않게 했습니다.
- 저장 형식은 BLUE7을 유지하므로 0.7 저장을 그대로 읽습니다.

## 0.7 고급 교역 주문서

- 상품의 소개·오늘 단가·보유 수량을 확인하고 매입/판매 주문서를 엽니다.
- **수량 지정**: 직접 입력, 슬라이더, +/− 조절, 5개/10개 바로 선택.
- **금액 지정**: 예산 직접 입력 또는 100/500/1000 G 선택. 단가로 나눈 정수 수량을 예산·잔액·화물 공간 안에서 계산합니다. 남는 예산을 표시합니다.
- **최대 구매 / 전량 판매**: 살 수 있는 최대 수량이나 선택 상품의 전체 재고를 계산합니다.
- **비상금 200 G 남기기**: 매입 시 기본 켜짐. 필요하면 해제할 수 있습니다. 이 금액이 모든 항로의 보급비를 보장하는 것은 아닙니다.
- 주문서에서 단가·수량·총액·거래 후 금화·화물 공간을 확인한 뒤 확정합니다. 이야기 완료 보상은 별도로 표시하며 잔액에 포함합니다.
- 미리보기는 저장이나 재고를 변경하지 않습니다. 취소는 무료입니다. 견적 이후 진행이나 시세가 바뀌면 새 견적을 요구하며 중복 클릭으로 두 번 거래하지 않습니다.

## 0.6 마을 RPG와 항해 연출

- 시작 화면이 항구 마을입니다. 지역별 7가지 마을에서 교역소·조선소·주점·광장의 이름이나 아래 버튼을 눌러 입장합니다.
- 교역소에는 상인과 실내 배경, 상품 진열 선택이 있습니다. 조선소는 작업장, 주점은 선술집 그림을 표시합니다.
- 주점에서 60 G·하루를 써 사기를 25 회복합니다. 사기 85 이상은 포격 +2, 25 미만은 포격 −1·보급비 +5%입니다. 항해마다 사기 3~15가 감소합니다.
- 항구별 첫 소문은 명성 +1을 줍니다. 선장 등급과 활동 경험은 탐험·의뢰·전투·이야기 기록을 보여줍니다.
- 출항하면 선박 그림이 파도·물살과 함께 5.5초 동안 흔들리며 이동합니다. 배 등급별 외형, 항로 진행 표시, 입항 건너뛰기를 지원합니다.
- 항해 비용과 사건은 한 번만 처리해 먼저 저장합니다. 중단·재실행·파일 불러오기는 항해 장면을 다시 보여주며 중복 결제하지 않습니다.
- 저장 형식 BLUE7은 이전 BLUE1~6을 읽습니다. 기존 Android 9 PC 에뮬레이터에 업데이트 설치하고 실제 화면 및 불러오기/입항 검사를 통과했습니다. 실제 휴대폰은 아직 검증하지 않았습니다.
- 그림 생성 정보와 정확한 프롬프트: `art/rpg-scenes-v1.md`.

## 설치

`BlueHorizon.apk`를 안드로이드 휴대폰으로 옮겨 열어 설치하세요. 기존 0.1 버전 위에 업데이트 설치할 수 있도록
같은 패키지·개발 서명을 유지하고 버전 번호를 올렸습니다. 실제 기기 업데이트 설치는 아직 확인하지 못했습니다.
요청이 나오면 APK를 연 파일 앱에 대해 ‘알 수 없는 앱 설치’를 허용하세요.
개발용 서명 시제품이며 Play Store에 게시된 제품은 아닙니다.

## 첫 항해

1. 교역소에서 목재 5개를 매입합니다.
2. 리스본에서 출발해 항해 지도의 세비야를 선택하고 출항합니다. 지도 아래 항구 버튼도 이용할 수 있습니다.
3. 세비야 교역소에서 목재 5개를 한 번에 판매합니다.
4. 항해일지의 다음 목표를 따라갑니다. 각 장 완료 시 700 G를 받습니다.

7개 해역에 각각 8개씩, 총 **56개 실제 지명 항구**가 있습니다. 원작과 동일한 항구 목록을 복제한 것은 아닙니다.
세계 지도와 해역별 확대 지도를 전환할 수 있습니다. 해역 선택 버튼은 좌우로 밀어 이용합니다.
확대 지도에서 항구 이름이나 점을 누르거나, 아래 항구 목록에서 목적지를 선택하세요.

| 해역 | 항구 |
|---|---|
| 북해·서유럽 | 리스본, 세비야, 런던, 암스테르담, 함부르크, 스톡홀름, 오슬로, 낭트 |
| 지중해 | 마르세유, 제노바, 베네치아, 아테네, 이스탄불, 알렉산드리아, 튀니스, 알제 |
| 아프리카 | 카사블랑카, 아르긴, 카보베르데, 상투메, 루안다, 케이프타운, 소팔라, 모잠비크 |
| 인도양 | 아덴, 무스카트, 호르무즈, 고아, 캘리컷, 콜롬보, 몸바사, 말린디 |
| 동남아시아 | 말라카, 아체, 팔렘방, 바타비아, 마카사르, 마닐라, 반텐, 딜리 |
| 동아시아 | 마카오, 취안저우, 항저우, 부산, 나가사키, 나하, 호이안, 단수이 |
| 아메리카 | 하바나, 산토도밍고, 산후안, 베라크루스, 카르타헤나, 페르남부쿠, 바이아, 부에노스아이레스 |

상품 6종, 선박 3종, **창작 이야기 8장**과 이후 자유 항해를 포함합니다.
리스본의 의뢰 → 북쪽 조류표 → 알렉산드리아 도서관 → 아프리카 남단 → 계절풍 교역 →
동아시아 차 교역 → 대서양 관측소 → 리스본의 공동 해도 출판으로 이어집니다.
원작의 시나리오·등장인물·대사를 재현하지 않습니다.

출항 전 경유 항구·거리·일수·일반/안전 항로의 비용과 선체 손상을 확인할 수 있습니다.
경유는 자동 항해 경로이며 **방문 기록은 목적지에만 남습니다.** 목표 항구를 직접 선택해 정박해야 합니다.
유럽에서 인도양으로 가는 항로는 아프리카 남단을 돕니다. 수에즈·파나마 운하 지름길은 없습니다.
좌표·해안선·항로와 일수는 게임용으로 단순화했으며 역사·실제 항해의 정밀 재현이 아닙니다.
항해는 보급비와 시간을 소모하며 선체가 손상됩니다. 안전 항로는 비용이 높고 손상이 적으며, 먼 항해일수록 소모가 증가합니다.
선체 25 미만이면 조선소에서 수리해야 합니다. 금화가 부족하면 ‘항구 일거리’를 반복할 수 있습니다.
투자는 항구마다 3단계까지 가능하며 판매가와 명성을 높입니다. 기본 가격은 항구별 고정이며,
담당 동료·항구 투자·라이벌 상권에 따라 실제 매입/판매 가격이 달라집니다.
실시간 해전과 여러 척의 함대 운용은 없습니다. 해적전은 선택형 턴제로 진행합니다.

## 항해 사건·의뢰·탐험

첫 출항은 안내를 위해 조용히 진행합니다. 이후 일반 항로는 매 출항, 안전 항로는 두 번에 한 번
사건이 발생합니다. 목적지에 도달하는 과정의 사건이며, 선택을 끝내기 전에는 거래·수리·추가 출항을 할 수 없습니다.

| 사건 | 선택과 결과 |
|---|---|
| 폭풍 | 돛 줄이기 / 위험을 감수하고 돌파 / 보급비를 내고 기다리기 |
| 해적선 | 턴제 해상전 / 통행료 교섭 / 선체 손상을 감수하고 회피 |
| 난파선 | 갑판 물자 수색 / 확률형 잠수 탐색 / 위치 공유 |
| 조난 신호 | 보급을 나눠 구조 / 시간을 들여 예인 / 지원 신호 전달 |
| 항구 축제 | 화물 기증 / 항해담 공유 / 환영 선물 받기 |
| 수상한 상자 | 위험한 상자 매입 / 서류 확인 / 제안 거절 |
| 돌고래와 순풍 | 해류 관측 / 보급 절약 / 갑판 정비 |
| 작은 섬 | 해변 조사 / 내륙 탐험 / 해도에 위치 표시 |

선택 전 표시된 비용·성공률·선체 손상을 확인하세요. 실패해도 선체는 최소 1로 남으며,
사건을 마친 뒤 항구 일거리로 수리비를 모을 수 있습니다. 해상전에는 포격·회피 사격·도주가 있고,
최대 12턴에 종료됩니다. 선박 등급에 따라 공격력이 달라집니다. 도주는 금화가 없어도 가능합니다.
화물 유실·기증·도주 시 화물은 상품 목록의 첫 보유 상품부터 1개 소모됩니다.

항해 화면이나 일지의 **‘의뢰 · 탐험 · 달성 기록’**을 열면 다음을 볼 수 있습니다.

- 납품 의뢰: 화물을 직접 준비해 기한 안에 목적지에서 납품합니다. 화물은 소모되고 금화·명성을 받습니다.
  한 번에 하나만 받을 수 있고, 기한이 지난 의뢰도 위약금 없이 취소할 수 있습니다.
- 기념품: 난파선·섬 탐험에서 7개 해역의 기념품을 모읍니다. 같은 해역은 중복 기록하지 않습니다.
- 달성 기록 8개: 첫 교역·3해역 방문·기념품 완성·해상전 승리·구조·의뢰·56항구 방문·이야기 완료.
  달성한 보상은 한 번만 받을 수 있습니다.

사건의 미리 정해진 결과값·전투 중 적 선체·턴·의뢰·기념품·수령한 보상도 저장합니다.
앱 재실행이나 파일 불러오기 후 미해결 사건을 이어서 처리합니다.

## 라이벌 상단과 납품 경주

‘라이벌 상단 · 동맹과 경주’에서 세 상단과 서신을 주고받고 관계를 쌓습니다.

| 상단 / 대표 | 기반 해역 |
|---|---|
| 아스트라 상회 / 레온 | 북해·서유럽, 지중해, 아메리카 |
| 청람 교역단 / 린 | 동남아시아, 동아시아 |
| 사프란 연맹 / 사미르 | 아프리카, 인도양 |

게임 속 7일마다 비동맹 상단의 지역 경쟁 압력은 +1, 동맹이면 −1입니다(0~80).
한 번의 긴 항해에서 반영하는 변화는 최대 8입니다. 판매는 화물 5개당 압력 −1(최소 1),
항구 투자는 −5이며 비동맹 상단과의 관계는 판매마다 −1, 투자마다 −2입니다.
비동맹 압력 60 이상이면 현지 매입 수수료 3%, 압력 0이면 판매 비율 +2%p입니다.
동맹은 매입 수수료 면제와 판매 비율 +2%p를 줍니다. 담당/투자/상단 보너스의 총 판매 비율은
94%를 넘지 않으며 이안 할인까지 적용한 최저 매입 가능가보다 최소 1 G 낮게 제한해, 담당을 바꾸더라도 같은 항구에서 손실 없이
매매하며 금화나 명성을 얻을 수 없습니다.

서신 교류는 상단별 7일 간격이며 성공 시 하루가 지납니다.
선물은 150 G로 관계 +12, 납품 실적 공유는 해당 상단에 아직 쓰지 않은 완료 의뢰 1회로 관계 +10입니다.
비동맹 기반 해역에서 명성 20 이상이면 공개 경쟁(현지 압력 −8, 관계 −8)을 제안할 수 있습니다.
관계 40·명성 15·500 G로 동맹을 맺습니다. 동맹 종료는 관계 −20, 하루 경과이며 혜택이 사라집니다.

납품 경주는 현재 해역 상단과 상품 5개를 놓고 경쟁합니다. 참가비 100 G, 한 번에 하나,
참가 후 7일 간격입니다. 기한은 개조 전 항로 일수+3일이므로 돛 개조로 여유를 확보할 수 있습니다.
화물은 직접 준비하고, 목적지에서 기한 당일까지 납품하면 소모됩니다. 승리 시 금화·명성 +3·관계 +8,
해당 지역 압력 −12를 얻습니다. 기한 초과나 포기는 화물 유지, 참가비 미반환, 압력 +5·관계 −3입니다.
경주 화물은 일반 의뢰와 별도로 소모되며 경주 승리는 일반 의뢰 완료 횟수에 포함되지 않습니다.
동맹 상단과도 친선 경주가 가능합니다. 경주·협상·동맹 변경은 미해결 항해 사건을 마친 뒤 할 수 있습니다.

## 동료·선박·음악

조선소에서 돛·대포·보강 선체·화물 창고를 각각 3단계까지 개조할 수 있습니다.
단계당 슬롯 1개를 사용하며 슬루프/캐러벨/갤리온의 슬롯은 3/5/7개입니다.
돛은 단계당 항해 일수를 5% 줄이고(올림, 최소 이틀), 대포는 포격 +4·회피 사격 +2,
보강 선체는 최대 선체 +15·일반 항해/해상전 피해 −1, 창고는 적재량 +8을 줍니다.
한 단계 해제 시 해당 단계 비용의 50%를 환급합니다. 화물이 새 한도를 넘으면 창고 해제를 막습니다.
보강 선체를 장착하면 추가된 최대치만큼 현재 선체도 늘며, 새 배로 바꿔도 모든 부품이 유지됩니다.

- ‘동료’ 메뉴에서 서린·이안·미라·나디아·타보·아유의 초상화와 소개를 볼 수 있습니다.
  서린과 이안은 처음부터 함께하며, 나머지 인물은 이야기 2·3·4·5장 완료 후 순서대로 합류합니다.
  서린은 새 항구 첫 방문에 명성 +1을 얻습니다. 다른 동료는 전문 담당 두 자리에 배치해 능력을 적용합니다.
  이안: 매입가 −5%, 미라: 보급비 −10%, 나디아: 잠수·내륙 탐험 성공률 +10%p,
  타보: 일반 항해·해상전 선체 피해 −2(최소 1), 아유: 판매 비율 +5%p(총 상한 94%).
  처음에는 이안만 배치돼 있습니다. 사건 도중 배치 변경과 개인 기록 보상 수령은 불가능합니다.
  동료마다 개인 목표와 짧은 후일담을 넣었으며, 조건 달성 시 기록을 열고 보상을 한 번 받습니다.
- 항해 지도에는 현재 이야기에 맞는 동료의 안내가 표시됩니다. 장 완료 시 초상화와 함께 이야기가 열립니다.
- ‘다음 목표 해역 보기’로 관련 지도를 바로 엽니다.
- 교역소는 선택한 수량을 현재 항구에서 새로 매입해 일반 항로로 운송했을 때의 추천 판매처와 예상 차익을 보여 줍니다.
  편도 보급비를 반영하며 수리비·귀환비는 제외합니다. 기존 화물의 실제 매입 원가와는 다른 견적입니다.
- 자체 합성한 창작 연주곡 2개(항해 지도 / 항구 화면)와 효과음 8개(버튼·거래·출항·장 완료·실패·선박 구입·포격·발견)를 포함합니다.
  일지에서 BGM과 효과음을 따로 켜고 끌 수 있으며 설정은 기기에 유지됩니다.
  앱이 백그라운드로 가거나 소리 재생 권한을 잃으면 재생을 멈춥니다. 다른 앱의 일시적인 소리 요청에는 음악을 낮춥니다.
- 이미지 제작: 내장 image_gen. [최종 프롬프트와 배치](art/characters-v1.md).
- 오디오 재생은 실제 Android 기기에서 아직 청취·호환성 검증하지 못했습니다.

## 저장

거래·항해·일거리·투자·수리·선박 구입 후 자동 저장하고, 앱이 백그라운드로 갈 때도 저장합니다.
저장 파일은 버전·체크섬·값의 범위를 검증합니다. 최신 저장을 읽을 수 없으면 이전 저장으로 복원합니다.
항해일지에서 파일을 내보내고 불러올 수 있습니다. 불러오기는 현재 진행을 교체합니다.
앱을 삭제하거나 앱 데이터를 지우기 전에 파일을 내보내 다른 위치에 보관하세요.
클라우드 자동 동기화 기능은 없습니다.

0.1 버전 저장은 자동 이전하거나 파일로 불러올 수 있습니다. 금화·화물·선박·날짜·명성·투자를 유지합니다.
가상 항구는 리스본·세비야·알렉산드리아·캘리컷·항저우에 대응해 이전합니다.
**0.1에서 넘어올 때는 이야기 구성이 달라졌으므로 새 세계 이야기를 첫 장부터 시작합니다.**
0.2·0.3 저장은 기존 이야기 단계와 자산을 그대로 유지하며 사건·의뢰 기록만 새로 시작합니다.
담당 배치·개인 기록·부품·상단 관계·지역 경쟁·경주도 저장합니다. 새 저장 형식 BLUE6은 BLUE1~5를 읽습니다.
기존 저장의 이야기·금화·화물·전투·의뢰·담당·부품은 유지하며, 새 상단 시스템은 불러온 게임 날짜부터 시작합니다.
이전에 투자한 항구는 초기 경쟁 압력에도 반영합니다.

## 개발과 확인

`python android-blue-horizon/tools/build.py` — JVM 규칙 검사 후 컴파일·APK 생성·서명 검증.
JDK/Android SDK는 `~/.codex/android-deckball-tools`를 사용합니다.
`python android-blue-horizon/tools/check_quality.py` — 함수 길이·복잡도 검사.
게임 엔진은 Android 없이 JVM에서 검사합니다. 테스트는 거래·수리·이야기 완료·파산 회복 외에
전체 항구 쌍의 항로 연결·대칭성, 32번 이후 방문 비트, 세계 항구 투자 저장,
실제 BLUE1 저장 파일 이전, 정상 동작만으로 8장 캠페인 완료, 지도 이름표 경계·겹침·터치,
해상 항로의 해안선 표본 검사를 포함합니다.
실제 휴대폰에서의 화면·터치·파일 선택기 동작은 별도 확인이 필요합니다.

`pytest -q android-blue-horizon/tests/test_media_assets.py` — 음원 PCM 형식·음량·클리핑·길이,
초상화 영역, APK 내 비압축 음원 포함을 검사합니다. APK를 먼저 빌드해야 합니다.
`python android-blue-horizon/tools/generate_audio.py` — 표준 라이브러리만으로 창작 음원을 다시 생성합니다.

빌드 참고: [Android 공식 명령줄 빌드 안내](https://developer.android.com/build/building-cmdline).

지도 데이터: [Natural Earth land](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson),
[공개 사용 조건](https://www.naturalearthdata.com/about/terms-of-use/). 해안선과 생성된 항로를 앱에 포함하므로 실행 중 다운로드하지 않습니다.
`generate_coast.py`로 지도 데이터를 생성하고 `generate_routes.py`로 해상 경유점을 생성합니다.
재생성 도구에는 Pillow가 필요합니다. 일반 APK 빌드에는 네트워크나 Pillow가 필요하지 않습니다.

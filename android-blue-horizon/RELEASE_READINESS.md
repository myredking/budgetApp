# 0.12 완성도 점검 — 2026-11-07

혼자 즐기는 오프라인 Android 시제품의 개선판입니다. 자동 검사 통과를 상용 게임 완성도 100점으로 해석하지 않습니다.

## 확인한 내용

- 0.12는 상황별 효과음 7종(총15종), 독립 볼륨, 일지 미리 듣기를 추가했습니다. 전체 JVM과 두 캠페인을 재검사했으며 미디어 검사는 21개입니다. 음원 데이터 검사가 실제 스피커 청취 평가를 대신하지는 않습니다.
- 0.11은 자원 그림 HUD·다섯 그림 메뉴·마을 시설 아이콘·황동 패널을 적용했습니다. 아래 캠페인 결과는 게임 규칙이 동일한 0.10 검사 기록입니다.
- 실제 거래·항해·해상 사건·저장 재접속을 거쳐 8장 엔딩에 도달하는 두 경로를 자동 검증했습니다. 본 줄거리 중심은 409일/29출항, 일곱 해역 보물·강적 전체 완료 경로는 526일/54출항입니다. 게임 내 날짜이며 사람의 실제 플레이 시간은 아닙니다.
- 선박 성장의 항해 효율, 목표 화물 보호, 1×/2×/4× 연출, 귀환 비용을 포함한 자금 안내를 검증했습니다. 자금 부족 시 0/50/40 G 상황에서 일거리 버튼으로 회복할 수 있습니다.
- Android 9와 Android 15 에뮬레이터에서 거래·키보드·항해 복원·자동 입항·마을 이동·대화·강적·자금 회복 검사가 통과했습니다. 검사 후 기존 진행과 설정을 복원합니다.
- Android 15에서 1080×2340, 420dpi/기본 글자 및 480dpi/글자 1.3배를 확인했습니다. 배속·건너뛰기 버튼이 보이는 확대 화면 캡처를 보관했습니다. 해상도는 S26 규격을 참고했고 밀도는 검사 조건입니다.
- Android 15의 실제 시스템 파일 선택기에서 BLUE8 파일을 Downloads에 내보내고 같은 파일을 선택해 1일째 진행을 복원했습니다. 개인 저장이 아닌 검사 전용 새 게임을 사용했습니다. 표본은 `tests/fixtures/v8-export-save.txt`, 결과 화면은 `verification/v0.10-native-backup-restored.png`입니다.
- 전체 Java 검사, 미디어 검사 14개, 함수 길이·복잡도 검사 및 APK 서명 검증을 통과했습니다. 기능별 QA 재검토를 진행했습니다.

## 남은 검증

- 사용자가 현재 휴대폰을 연결하기 어려워 Galaxy S26 실기/One UI 화면·터치·발열·배터리·프레임률은 확인하지 못했습니다. 에뮬레이터 결과가 실기 검증을 대신하지 않습니다.
- 처음 접하는 사람이 설명 없이 시작해 엔딩까지 플레이하는 관찰과 장시간 재미·난이도 평가가 필요합니다. 자동 경로가 모든 선택·무역 전략·실수 조합을 대표하지는 않습니다.
- 앱 삭제·기기 변경 전 파일 백업을 해야 합니다. 현재 로컬 저장과 수동 파일 백업을 제공하며 클라우드 동기화는 없습니다.

설치 파일은 `BlueHorizon-0.12.0.apk`입니다. 이전 설치를 유지한 채 업데이트하면 로컬 진행을 이어갑니다.

# 타워 프론트 3.2

Android 8.0(API 26) 이상에서 실행되는 오프라인 타워 점령 전략 게임입니다.
설치 파일은 `TowerFront.apk`입니다. 기존 1.x/2.x 앱과 같은 앱 식별자와 개발 서명을 유지하여 업데이트 설치할 수 있습니다.

## 플레이
- 아군 타워를 선택한 뒤 목표를 터치하거나 드래그하여 출병합니다.
- 하단 출병 버튼으로 50%와 100%를 선택합니다. 아군 타워를 목표로 삼으면 증원합니다.
- 기본 타워는 병력을 자동 생산합니다. 생산 타워는 생산량 1.7배, 기동 타워는 출발 병력의 이동 시간이 40% 짧습니다.
- 중립 타워는 생산하지 않습니다. 점령 후에는 타워 종류와 레벨이 유지됩니다.
- 선택한 아군 타워는 병력 20 / 40을 사용해 Lv.2 / Lv.3으로 강화할 수 있습니다. 생산량은 기본 대비 150% / 200%가 됩니다.
- 적 타워와 이동 중인 적 병력을 모두 제거하면 승리합니다.

## 캠페인과 저장
12개 작전과 쉬움·보통·어려움 난이도를 지원합니다. 난이도별로 순서대로 작전을 해금하고 최고 별 기록을 저장합니다.
90초 이내 승리하면 별 3개, 180초 이내면 2개, 그 이후 승리는 1개입니다. 마지막 작전 승리 후 작전 지도로 돌아가 재도전할 수 있습니다.

전투는 플레이 시간 5초 주기, 일시정지, 백그라운드 전환 시 저장됩니다. 앱을 재실행하면 시작 화면의 이어하기로 타워·강화·이동 병력·전투 시간을 복원합니다.
강제 종료 시에는 마지막으로 완료된 저장 시점부터 이어집니다. 백그라운드에서는 시간이 진행되지 않으며, 복귀하면 일시정지 상태로 기다립니다.
이전 버전에서 해금했던 작전은 보통 난이도 기록으로 옮깁니다. 새 작전 시작 시 기존 전투를 교체하기 전에 확인합니다.

효과음과 터치 진동을 설정에서 각각 끌 수 있습니다. 광고·계정·네트워크·외부 저장소 권한을 사용하지 않습니다.

## 설치와 빌드
APK를 휴대폰으로 옮겨 열고 해당 파일 제공 앱의 설치 허용을 선택하세요.

기존 로컬 Android SDK/JDK와 서명 키를 사용합니다.

```text
python android-tower-front/tools/build.py
pytest tests/test_tower_front.py -q
python -m lizard android-tower-front/src android-tower-front/tests -L 50 -C 10 -w
radon cc android-tower-front/tools tests/test_tower_front.py -s
```

빌드는 깨끗한 임시 디렉터리를 사용하고, Windows 한글 경로에서 aapt2 리소스 처리가 실패하지 않도록 ASCII 경로에 리소스를 임시 복사합니다.
상세 검증 기록과 남은 범위는 `QA.md`를 참조하세요.

## 3.1 전투 연출
병력 도착 시 타격 불꽃과 피해 숫자, 증원 십자 입자와 실제 증가량, 점령 파동과 타워 확대 효과를 표시합니다.
승리 시 3.2초 동안 축하 입자가 재생되며 결과 화면의 버튼 영역은 가리지 않습니다.
설정에서 전투 연출을 끌 수 있고, 소리·진동과 독립적으로 저장됩니다. 타격·증원·점령 도착 알림음을 구분합니다.
연출은 일시정지 중 멈추며, 전투 저장 데이터에는 포함하지 않습니다.


## 3.2 전략과 난이도
- 4번째 작전부터 방패 모양의 방어 타워가 등장합니다. 적·중립 타워에 대한 공격 피해는 75%로 계산하며 소수점을 올립니다. 16명 공격은 피해 12, 1명 공격은 피해 1입니다.
- 방어 타워도 생산·강화·점령이 가능하며 아군 증원에는 피해 감소를 적용하지 않습니다.
- 쉬움은 초기 예비 병력을 늘리고 추가 거점을 중립으로 시작합니다. 보통은 첫 작전 적 병력을 완화하고 7번째 작전부터 두 번째 적 기지와 아군 방어 전초기지를 함께 배치합니다.
- 새 배치는 새로 시작한 전투에 적용합니다. 저장된 기존 전투는 이전 타워·병력 상태 그대로 이어집니다.
- 작전 지도에서 뒤로 가기는 시작 화면으로 돌아갑니다. 전투에서는 뒤로 가기 한 번으로 일시정지, 다시 누르면 시작 화면으로 돌아갑니다.

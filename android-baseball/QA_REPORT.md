## 실제 앱 실행 검사

1. APK 설치 → 홈의 3D 경기장 표시
2. 경기 시작 → 카메라 전환 → 투구 준비/릴리스 → 판정 표시
3. 경기 나가기 확인 → 홈 → 라인업 → 홈
4. 구단 운영 시작: 예산25000만원 / 보유10명
5. 이승엽 관심 등록 → 조사500만원 결제 → 2일 진행 → 완료 보고서
6. 이승엽 영입8920만원 → 예산15580만원 / 보유11명
7. 어려움 난이도 변경 → 앱 강제 종료/재실행 → 난이도·예산·날짜·관심 명단 복원
8. 자동 경기 3이닝 완주 → 패배800만원 보상 → 예산16380만원 / DAY4
9. 최종 수정 APK 재설치 → 자동 경기 종료 시 FINAL 표시 확인
10. 다시 경기 → 수동 조작 상태 및 투구 갱신 재개 → 홈 복귀
11. 확인한 실행 구간의 AndroidRuntime 로그에 FATAL EXCEPTION 없음

## 발견하여 수정한 문제

- 비정상 안타 거리·구종·코스·타이밍 입력
- 모바일 최소 정밀도에서 넘칠 수 있던 표면 노이즈 계산
- 움직이는 프레임마다 전체 선수 메시를 다시 만들던 메모리 할당
- 자동 모드 전환 시 남던 투구 타이밍 표시
- 작은 가로 화면에서 아래 버튼 때문에 목록 높이가 부족하던 배치
- 좁은 조작 메뉴의 구종/코스 버튼 줄바꿈
- 홈플레이트에서 멀어지던 스윙 궤적
- 경기 종료 후 ‘4회 초’ 표기와 지난 발동 안내
- 종료 뒤 불필요한 갱신/저장 반복과 재경기 갱신 재개

## 남은 한계

상용 게임 수준의 실사 얼굴·고해상도 유니폼·모션 캡처는 없다. 실제 선수 얼굴을 재현하지 않은 자체 기본 3D 모델이다. 타격 결과는 확률 판정이며 물리 충돌 시뮬레이션이 아니다. 전체 KBO 선수 DB·리그 일정/순위·장기 성장/계약 협상 시스템은 포함하지 않는다. 실제 휴대폰의 GPU 호환성·발열·배터리·장시간 플레이는 미검증이다.

# 블록 가든
광고 및 네트워크 권한 없는 오프라인 Android 블록 퍼즐. Android 8.0 이상.

BlockGarden.apk를 휴대폰으로 옮겨 열고 설치하세요. 요청 시 해당 파일 앱의 알 수 없는 앱 설치를 허용하세요.
블록을 고르고 보드의 칸을 누르거나, 블록을 끌어 보드에 놓으세요. 터치한 칸이 블록의 왼쪽 위 기준입니다.
8×8 보드의 가로·세로 줄을 채우면 지워집니다. 블록 3개를 모두 쓰면 새 블록이 나옵니다.
더 이상 놓을 수 없으면 게임이 종료됩니다. 새 게임 버튼으로 다시 시작하세요.
배치한 블록 하나당 10점, 한 번에 지운 줄 수의 제곱 × 100점. 진행 상황과 최고 기록이 기기에 저장됩니다.
원작의 이미지·음원·상표를 사용하지 않은 독립 제작 게임입니다.

개발: python android-block-garden/tools/build.py
Android SDK 35 및 JDK는 기존 ~/.codex/android-deckball-tools 환경을 사용합니다.
개발용 서명 APK이며 Play Store 등록용 배포 서명은 별도입니다.
JVM 엔진 테스트 및 APK v2/v3 서명 검증 완료. 실제 Android 기기 화면·터치 검증은 수행하지 못했습니다.

1.0.1: 저장된 보드·블록·색상 범위 검증, 초기 패 즉시 저장, 종료 안내 복원. 17개 검사 통과. 실제 기기 실행 검증은 미수행.

## 1.1.0 미션 모드
화면 위 모드 선택에서 자유 모드 / 미션 모드를 고르세요. 각 모드는 별도로 저장되며 이어서 할 수 있습니다.
1: 500점 달성
2: 3줄 제거
3: 20회 배치 안에 5줄 제거
4: 별 2칸 제거
5: 35회 배치 안에 별 2칸 제거
6: 35회 배치 안에 별 4칸 제거
7: 35회 배치 안에 별 표시 장애물 4칸 제거
8: 25회 배치 안에 별 표시 장애물 4칸 제거
별이 놓인 가로/세로 줄을 완성하면 별도 지워집니다. 장애물 칸에는 새 블록을 놓을 수 없으며 해당 줄을 완성해 제거합니다.
성공하면 다음 스테이지 버튼으로 진행합니다. 실패 시 미션 다시 시작을 누르세요. 8단계 완료 후 처음부터 반복할 수 있습니다.
29개 엔진·미션·저장 데이터 검사 및 복잡도 검사, APK 서명 검증 통과. 실제 Android 화면·저장소 통합 실행 검증은 미수행입니다.

## 1.2.0 — 100단계 확장
총 미션 수를 100개로 확장했습니다. 1~8단계와 기존 저장 기록을 유지하며 8단계 다음에는 9단계로 진행합니다.
9단계부터 점수 / 줄 제거 / 별 / 장애물 순으로 4단계씩 반복합니다.
단계 묶음이 올라갈수록 점수 목표는 800~4,100점, 줄 목표는 5~16줄, 별·장애물은 3~8칸으로 증가합니다.
배치 제한은 60회에서 38회까지 줄어듭니다. 별·장애물 위치도 단계별로 달라집니다.
100단계 완료 후 처음부터 다시 도전할 수 있습니다.
기존 29개 검사와 진행 경계 5개, 추가 92개 단계별 7개 판정 검사를 통과했습니다.
실제 기기에서 100개 단계의 완주 가능성과 체감 난이도는 아직 검증하지 못했습니다.

1.2.1: 잘못된 별 저장 데이터 검증 추가. 100단계 × 300회 자동 플레이에서 전 단계 클리어 사례와 성공 경로 재생을 확인했습니다. 상세 기록은 verification/README.md를 참고하세요.

1.2.2: 97단계 목표를 4,100점/38회에서 2,800점/50회로 조정했습니다. 동일 자동 플레이 seed 0~299에서 성공 1/300 → 100/300. 성공 경로 재생 검증 완료. 사람의 성공률이나 모든 패에서의 성공을 보장하는 수치는 아닙니다. 기존 97단계 진행도 수정된 조건으로 이어집니다.

## 1.2.3 — 터치 조작 개선
블록을 선택한 뒤 보드 칸을 누르는 방식은 그대로 사용할 수 있습니다.
드래그는 기기의 기본 이동 임계값을 넘었을 때 시작하며, 손가락 위 약 1.5칸에 블록 중심을 맞춰 미리보기를 표시합니다.
가장자리에서 드래그하는 경우 블록 전체가 보드에 들어오도록 위치를 맞춥니다. 이미 놓인 블록과 겹치는 배치는 허용하지 않습니다.
빈 패를 끌어 이전 블록이 움직이는 상황, 메뉴에서 손을 뗄 때 배치되는 상황을 방지하고 활성 손가락 이탈·터치 취소를 처리합니다.
터치 좌표·임계값·가장자리·취소 자동 검사 및 기존 게임 검사 통과. 실제 Android 기기에서 조작감은 아직 확인하지 못했습니다.

## 1.3.0 — 시작 모드 선택 화면
앱을 새로 실행하면 자유 모드와 미션 모드를 고르는 시작 화면을 표시합니다.
자유 모드는 저장된 점수와 보드를, 미션 모드는 저장된 단계와 보드를 이어갑니다. 미션 버튼에는 현재 저장된 단계가 표시됩니다.
게임 위 모드 선택이나 Android 뒤로가기를 누르면 진행을 저장하고 시작 화면으로 돌아갑니다.
Android 기본 버튼과 스크롤 화면을 사용해 작은 화면·큰 글자에서도 모드를 고를 수 있게 했습니다.
화면 전환 상태 테스트와 기존 게임·터치 테스트, 복잡도·서명 검사 통과. 실제 Android 화면·터치·저장소 통합 검증은 미수행입니다.

## 1.4.0 — 줄 제거 타격감과 소리
줄 제거 시 약 0.55초 동안 블록 파편, 짧은 화면 흔들림, 추가 점수를 표시합니다. 여러 줄은 동시에 제거되며 중복 파편을 만들지 않습니다.
배치·줄 제거에 Android 시스템 설정을 따르는 짧은 터치 진동을 추가했습니다. 기기 진동 지원과 시스템 설정에 따라 느껴지지 않을 수 있습니다.
자체 생성한 12.8초 반복 BGM과 배치/줄 제거/미션 성공/실패/불가 배치 효과음을 APK에 포함했습니다. 네트워크 연결은 필요 없습니다.
시작 화면 또는 게임 하단의 소리·진동 설정에서 BGM, 효과음, 진동을 각각 켜고 끌 수 있으며 설정은 저장됩니다.
앱을 벗어나거나 오디오 포커스를 잃으면 소리를 멈추며, 다시 활성화하면 설정에 따라 음악을 재개합니다.
오디오 파형·음량 범위·파일 끝점 검사, 제거 셀 색상·교차 제거 중복 검사와 기존 게임 테스트 통과. WAV 6개가 APK에 비압축으로 포함되며 서명 검증을 통과했습니다.
실제 Android 기기의 재생·진동·오디오 포커스와 애니메이션 성능은 아직 실행 검증하지 못했습니다.
음원 재생성: python android-block-garden/tools/make_audio.py

## 1.5.0 — 반응성·블록 디자인·게임 종료 안내
드래그 시작 이동 임계값을 기존 절반으로 줄이고, 손가락을 따라 움직이는 블록을 보드 밖에서도 표시합니다.
보드 바탕과 광택·그림자가 있는 보석 스타일 블록 이미지를 캐시하고 글꼴·터치 설정을 재사용하여 드래그 중 반복 그리기 작업을 줄였습니다. 기기에서 프레임 시간·터치 지연을 직접 측정한 것은 아닙니다.
자유 모드 종료와 미션 성공·실패 시 결과 팝업에 종료 이유, 점수, 최고 기록, 줄 제거 수, 배치 횟수를 표시합니다. 다시 도전/다음 단계, 모드 선택, 보드 보기를 선택할 수 있습니다.
게임 하단에 게임당 1회 직전 배치 되돌리기를 추가했습니다. 되돌리기는 보드·별·패·점수·줄·배치 횟수를 함께 복구하며 최고 기록은 유지합니다. 사용 여부는 저장되지만 배치 스냅샷은 현재 앱 실행 중에만 사용할 수 있습니다.
시작 화면에 게임 방법 안내를 추가했습니다.
터치 임계값·결과 메시지·되돌리기 복사 테스트와 기존 게임·오디오 테스트 통과. 실제 Android 터치 반응·디자인·팝업 실행 검증은 아직 수행하지 못했습니다.

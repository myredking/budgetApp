# 출시 준비 검증 기록

이 기록은 자동화와 가상기기에서 확인한 범위입니다. 실제 휴대폰의 품질이나 100미션의 사람 플레이 재미를 대신하지 않습니다.

## 캠페인·저장

- 100미션×3난이도=300회 고정 정책 자동 플레이: 쉬움100승, 보통94승/6패, 어려움65승/35패.
- 사용 정책: 매0.4초 아군 거점마다 절반 출병 가능 대상을 탐색하고 증원 스킬을 사용. 업그레이드·보호막·가속을 활용하는 사람의 전략과는 다릅니다.
- 모든 정책 실행에서600초 시뮬레이션 제한 안에 승패가 결정됨. 쉬움은1→100 순차 해금 및 완료 확인.
- 별도300개 진행 중 전투에서 출병·보호막 사용 후0.5초의 실제 이동 병력 상태를 저장/복원. 이후5초 동안 원본과 복원본을 같은 간격으로 진행해 저장 상태가 정확히 일치하는지 확인.
- 재현: `python -m pytest tests/test_tower_front.py -q`. `FullCampaignTest`가 매번 전체 범위를 검사합니다. 다른 자동 전략의 승률과 직접 비교할 수 없습니다.

## 화면·조작

- 작은 화면/긴 화면/태블릿/짧은 창6비율×글자1/1.5/2배 레이아웃 검사.
- 최소48dp 버튼, 지도 확대·이동, 입력 좌표 변환, 상태/목표 카드 간격, 일시정지 제목과 메뉴 범위 검사.
- Android15 가상기기720×1280/밀도320/글자1.5배와1080×2340/밀도420에서 실제 화면 캡처 확인.
- 모드 카드 진입·뒤로 가기, 저장/이어하기, 타워 드래그 목표 표시/출병 수, 지도 밖 취소, 안내 단계와 설정 유지 실행 검사.

## 아직 확인되지 않은 범위

- 실제 Galaxy S26 및 One UI에서의 터치·진동·오디오, 전화/잠금/다른 음악과의 상호작용.
- 실제 기기의 장시간 발열·배터리·메모리·프레임.
- 사람의100미션 전체 플레이 및 반복 플레이 재미·학습 난이도·접근성 평가.
- 스토어 등록·배포 설정과 최종 배포 서명. 현재 APK는 기존 개발 서명을 유지하는 테스트 배포본입니다.

이 항목은 검증되지 않은 상태로 남겨두며, 자동 검사 통과만으로 완성도100%라고 표기하지 않습니다.

## 추가 실행 검증

- 정지 화면2초 추가 그리기: 기존 완료 화면53회→수정 후 완료/일시정지0회. 입력으로 재도전·이어하기 시 재개 확인. 가상기기 수치이며 실제 배터리 개선율은 측정하지 않았습니다.
- 배경음악의 홈 정지/복귀, 음소거 저장, 가상 수신 전화 중 정지/종료 후 복귀를 Android15 MediaPlayer 상태로 확인. 실제 통화·블루투스·다른 음악 앱 검증은 별도입니다.
- 프로젝트 tests 폴더313개 통과, 기존 별도 웹 런타임 검사1개 실패. 제한 없는 전체 수집은 외부 도구 배포 폴더의17개 수집 오류로 중단되었습니다. 게임 대상 검사는 모두 통과합니다.
